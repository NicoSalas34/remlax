# Building the manuscript

    pdflatex remlax && bibtex remlax && pdflatex remlax && pdflatex remlax

`remlax.tex` uses the Journal of Statistical Software class, `jss.cls`, with
`jss.bst`. Neither is vendored here and neither ships with a plain TeX Live
installation; both come from the journal's author package, or from CTAN:

    tlmgr install jss        # needs an administrator on a shared machine

The built PDF is deliberately **not** versioned. A committed binary drifts out
of step with its source without saying so, and a reader of the clone would then
be reading a manuscript that is no longer the one in `remlax.tex`.

Figures live in `figures/` and are referenced by repository-relative paths, so
they resolve from a fresh clone rather than from the machine that made them.
They are regenerated by the assembly script from the CSVs in
`benchmarks/results/`.
